# Kimi branding

`kimi.svg` contains the original K glyph from the Kimi wordmark served by
https://www.kimi.com/ (retrieved 2026-10-22).

Source asset: https://statics.moonshot.cn/kimi-web-seo/assets/Bqt7kity.js
(the SVG wordmark component, first path; geometry unchanged).

The square SVG uses currentColor for BB theme-aware icon masks. Kimi branding
belongs to Moonshot AI; the repository MIT license does not relicense this mark.
